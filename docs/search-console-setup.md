# CF Investing — Google Search Console setup

Status: prepared, verification token still required from Google Search Console.

## Recommended property

Create a **Domain property** for:

`cfinvesting.com`

Use the root domain only: no `https://`, no `www` and no path. A Domain property covers protocols and subdomains.

## Verification

1. In Google Search Console, add the Domain property `cfinvesting.com`.
2. Choose DNS verification and copy the exact TXT value Google provides. It will normally begin with `google-site-verification=`.
3. In Cloudflare DNS, add that TXT record to the root domain. Do not modify Worker, A/CNAME, MX, SPF, DKIM or DMARC records as part of this step.
4. Return to Search Console and request verification.
5. Keep the verification record in DNS after verification.

The repository intentionally does not contain a placeholder verification token because the value must be generated by the user's Search Console property.

## Sitemap

After ownership is verified, submit:

`https://cfinvesting.com/sitemap.xml`

The same sitemap is already advertised in `public/robots.txt`.

## Initial monitoring

For the first 30–60 days, review:

- indexing / page coverage;
- sitemap processing status;
- search queries and pages receiving impressions;
- canonicalization signals;
- mobile usability / Core Web Vitals when sufficient field data exists;
- unexpected legacy-domain URLs.

Do not treat absence from search results during the initial period as proof of a technical problem without checking Search Console coverage and URL inspection.

## Canonical domain policy

`https://cfinvesting.com/` is the canonical root. The defensive/legacy `cfinvestings.com` domain should not become a competing indexable property. If retained for web traffic, it should redirect path-for-path to the canonical domain after DNS, SSL and email dependencies are confirmed.
