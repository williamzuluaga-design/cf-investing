Arquitectura de descubrimiento

Fuente oficial → extracción estructurada → deduplicación → revisión humana.

Fuente oficial→Conector específico→Metadatos candidatos→Cola de revisión→Decisión humana
Límite: los conectores recopilan metadatos y enlaces seleccionados. No infieren hechos no divulgados, no republican páginas completas y no escriben directamente sobre el dataset público de proyectos.

Cobertura de conectores

BID Invest · XML

Base XML oficial con número de proyecto, país, fecha de publicación y otros campos cuando están disponibles. El catálogo HTML permanece como fallback.

CAF · extractor de campos

Extracción específica de número de operación, país, fechas de aprobación/actualización, tipo de riesgo, instrumento, sector y estado cuando el catálogo los expone.

Bancóldex · extractor de campos

Extracción específica de fecha del programa, cupo disponible, tamaño de empresa, destino de recursos, sector y cobertura geográfica.

IFC y Findeter

Registrados para integraciones posteriores. Permanecen inactivos en vez de forzarlos mediante un parser genérico de baja calidad.
