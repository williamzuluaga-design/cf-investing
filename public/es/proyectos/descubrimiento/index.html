PROJECT INTELLIGENCE · DESCUBRIMIENTO

Detectar candidatos automáticamente. Publicar solo después de revisar.

El descubrimiento ahora soporta conectores específicos por fuente. BID Invest usa su base oficial XML para capturar metadatos estructurados; CAF y Bancóldex continúan con descubrimiento de catálogos de baja frecuencia mientras se desarrollan sus conectores propios.

Flujo de descubrimiento

Dataset o catálogo oficial → candidato → revisión humana → registro normalizado.

Fuente registrada→Conector específico→Deduplicación→Cola de revisión→Decisión humana
Límite: el sistema conserva metadatos seleccionados como título, número de proyecto, país, fecha de publicación, sector o estado cuando la fuente oficial los expone. No publica automáticamente ni infiere datos financieros no divulgados.

Cola de revisión humana

Los metadatos estructurados mejoran el triage, no reemplazan la revisión.

La revisión debe confirmar identidad, relevancia Colombia/LATAM, instrumento, monto divulgado, etapa, fecha de fuente y si el candidato pertenece a Project Intelligence o a otro dataset de CF Investing.

Fase 3E · Conectores específicos por fuente

BID Invest · estructurado

El conector principal ya lee la base XML oficial. El alcance inicial prioriza registros de Colombia y Regional publicados en 2026 y conserva el catálogo público como fallback si el XML no puede procesarse.

CAF · catálogo

Se mantiene el descubrimiento activo desde el catálogo mientras se evalúa un extractor específico para metadatos y paginación.

Bancóldex · catálogo

Continúa el descubrimiento de programas de financiación. Un conector posterior podrá normalizar programa, cupo, beneficiarios, destino y vigencia cuando esos campos se expongan consistentemente.

IFC y Findeter

Siguen registrados pero no se consultan automáticamente. Cada fuente se activará solo después de definir una ruta confiable de extracción y revisión.
