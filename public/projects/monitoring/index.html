How it works

Low-frequency checks

The initial workflow checks registered record sources once per day. The registry can be expanded only for sources suitable for low-frequency monitoring.

Noise reduction

HTML scripts, styles and repeated whitespace are excluded before a SHA-256 hash is calculated, reducing some navigation and rendering noise.

Human-in-the-loop

A changed hash can reflect a material update or harmless editorial changes. The workflow therefore creates a review signal rather than rewriting the project dataset.

Phase 3C scope

Record monitoring first; source discovery next.

This first monitoring layer covers the primary pages of already-published records. Discovery of entirely new projects requires separate source registries or approved listing/search endpoints and should be implemented with source-specific rules, rate limits and terms-of-use checks.
