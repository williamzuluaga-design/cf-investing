Model scope and limitations

This first-pass model excludes taxes, working-capital movements, construction-period interest, depreciation, reserve accounts, sculpted debt service, covenants, contractual risk, refinancing risk and detailed CFADS definitions. A real project-finance review should extend the analysis to downside cases, contracts, debt structure and technical/legal/ESG diligence.
