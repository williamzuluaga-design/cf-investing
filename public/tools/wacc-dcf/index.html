Model scope and limitations

This simplified five-year FCFF model assumes one growth rate for years 1–5 and a Gordon-growth terminal value. It does not model detailed operating drivers, non-operating assets, minority interests, leases, option value, multiple valuation methods or transaction-specific adjustments.
