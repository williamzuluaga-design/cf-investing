Model scope and limitations

The profile uses a simple four-question scoring rule. Example allocations and scenario returns use static educational assumptions and are not forecasts, optimized portfolios or reconstructions of investable products. Real suitability analysis requires broader information about objectives, finances, liquidity needs, constraints and applicable regulation.
