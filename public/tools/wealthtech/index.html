Learning objective

Compare the same portfolio across different shocks, then rebalance and run the scenario again. The exercise highlights concentration, diversification and path-dependence rather than forecasting future returns.

Rebalancing exercise

Profile → allocate → shock → rebalance → compare.

1. Build

Create a portfolio and review its expected return, volatility, Sharpe ratio and simplified drawdown.

2. Stress

Apply a historical-style shock and identify which asset classes explain most of the simulated loss or resilience.

3. Rebalance

Move the portfolio toward a defensive, balanced or growth profile and observe how the same scenario changes.
